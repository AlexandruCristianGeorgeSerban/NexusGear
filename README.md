## 📖 Overview

**NexusGear** is a custom, full-stack e-commerce web application built from scratch to deliver a seamless shopping experience for gamers, developers, and remote workers. Designed with a mobile-first philosophy, the store connects technical enthusiast hardware with ergonomic workspace equipment into a unified buying journey.

The platform provides a complete customer lifecycle, from catalog discovery and dynamic cart management to secure webhook-verified Stripe sandbox payments, paired with an administrative back-office for inventory and order management.

---

## 🛠️ Core Technology Stack

* **Backend**: ASP.NET Core (.NET 10) - Layered monolithic architecture (Controllers, Service Layer, EF Core models).
* **Database**: SQLite via Entity Framework Core with migrations and automated seed scripts (30 products across 4 categories).
* **Frontend**: Bootstrap 5 + Bootstrap Icons for an accessible, responsive design down to a 360 px viewport.
* **Payment Gateway**: Stripe (Sandbox/Test Mode) utilizing verified asynchronous webhooks.
* **Testing**: xUnit automated testing suite covering cart calculations, inventory logic, and payment fulfillment.
